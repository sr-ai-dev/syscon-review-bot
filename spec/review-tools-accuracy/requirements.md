# 리뷰 도구 및 구조 개선 요구사항

## 배경

기존 `gpt-5.4-mini` 모델을 유지한 상태에서 저장소 조회, 분할 리뷰, 비용 제한 구조가 리뷰 정확도에 주는 효과를 검증한다. 모델 교체 효과와 구조 개선 효과를 분리하고, 운영 API 키가 접근할 수 없는 모델 때문에 리뷰가 중단되지 않게 한다.

## 요구사항

- 시스템은 기본 리뷰 모델로 `gpt-5.4-mini`를 사용해야 한다.
- 저장소 도구 사용이 기본 활성화된 경우, 시스템은 기본 설정에서 `read_file`과 `grep` 도구 호출을 허용해야 한다.
- 사용자가 `reasoning_effort`를 명시한 경우, 시스템은 Chat Completions reasoning 경로를 사용해야 한다.
- 사용자가 모델 또는 reasoning 설정을 명시한 경우, 시스템은 해당 설정을 기본값보다 우선해야 한다.
- 비용 제어가 활성화된 경우, 시스템은 `gpt-5.4-mini`의 버전이 명시된 신뢰 가격표를 사용해야 한다.
- 기본값 변경 시, 시스템은 README와 예제 설정에 동일한 모델 및 reasoning 동작을 표시해야 한다.

## 성공 기준

- 인자 없이 생성한 `GPTClient`가 `gpt-5.4-mini`를 호출한다.
- 기본 비용 정책이 `gpt-5.4-mini`만 허용한다.
- 비용 계산이 입력 `$0.75`, 캐시 입력 `$0.075`, 출력 `$4.50`의 1M token당 단가를 사용한다.
- 기본 `ReviewConfig`가 저장소 도구 사용 경로와 충돌하지 않는 reasoning 값을 제공한다.
- 명시적 `reasoning_effort=high` 동작의 기존 테스트가 유지된다.
- 전체 테스트가 통과한다.
